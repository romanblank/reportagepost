# Правила TypeScript/Next.js — Reportage Post

- `strict: true`; `any` запрещён (исключение — обоснованный `unknown` с сужением).
- Серверные компоненты по умолчанию; `'use client'` — только при реальной интерактивности.
- Строки UI — только через i18n-словарь; зашитые русские строки в JSX запрещены (глобальный задел).
- Деньги: integer в минорных единицах + код валюты; никакого float.
- Время: в БД и API — UTC ISO 8601; форматирование — только на отображении.
- Данные из внешних источников (формы, API, LLM-вердикты) — валидировать схемой (zod) на границе; внутрь — только типизированные объекты.
- LLM-выводы (премодерация) — обязательный программный guard ПОСЛЕ модели; вердикт модели никогда не применяется напрямую.
- Ошибки не глотать: либо обработка с фолбэком, либо проброс; `catch {}` пустой запрещён.
- Импорты через `@/`; относительные `../../..` запрещены.
- После любого изменения: `npm test` + `npm run build` (Verification Loop из CLAUDE.md).
